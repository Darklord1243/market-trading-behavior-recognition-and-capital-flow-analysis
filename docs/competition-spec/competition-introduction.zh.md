## 参赛规则

### 1. 报名资格

面向全球开放，高校、科研单位、企业等人员均可通过天池平台报名。选手仅可在**挑战组、初创组中选择一个组别**报名。报名挑战组的选手可**选择多个命题**参赛。

### 2. 组队规则

- 可单人成队或**最多 3 人**组队
- 每位选手只能加入**一支队伍**
- 挑战组范围内，每队可选**多个赛题**

### 3. 实名认证

所有选手需完成实名认证，未完成不可进入**B 榜**和**决赛路演**。

### 4. 信息要求

参赛队伍应按要求提供所有必要信息，必要时应按大赛组委会要求补充提供。

### 5. 限制条款

- 大赛组委会成员、专家评委及其研究团队，以及其他有机会接触赛题背景的相关人员，**无参赛资格**
- 蚂蚁集团（含集团内子公司）员工，可参赛排名，但**不参与评奖及领取奖金**

## 比赛流程

报名认证 → 代码提交 → 报告提交 → 决赛路演。

### 阶段一 — 报名认证

| | |
|---|---|
| **时间** | 2026年6月8日 10:00 — 7月20日 12:00 |
| **报名** | 登录赛题页，完成个人信息注册 |
| **组队** | 单人或最多 3 人；每人一队；可多赛题 |
| **实名认证** | **全体队员**须在 **7月20日 12:00 前**完成（天池个人中心 → 认证 → 支付宝），或访问 [tianchi.aliyun.com/home/identification](https://tianchi.aliyun.com/home/identification)。未完成认证的队伍取消资格 |

### 阶段二 — 代码提交

| | |
|---|---|
| **时间** | 2026年6月8日 — 7月24日 |
| **流程** | 下载训练数据，调试模型与代码，在线提交 |
| **评测** | 6月8日 10:00 起实时评测，每小时更新排行榜，**每天 3 次提交机会** |
| **结束** | 7月24日 17:00 |

**赛题一 A/B 榜时间**（与其他赛题不同，详见 [`topic-specifications-and-data.zh.md`](./topic-specifications-and-data.zh.md)）：

| 榜单 | 时间 |
|------|------|
| A 榜 | 6月9日 — 7月10日 23:59 |
| B 榜 | 7月13日 — 7月24日 17:00 |

> **B榜现行细则（提交窗口 / 9日 WMA / 评测截止）：** [`../official_guidance/b-board-rules.zh.md`](../official_guidance/b-board-rules.zh.md)

### 阶段三 — 报告提交

| | |
|---|---|
| **时间** | 2026年7月底 — 8月5日 |
| **对象** | 成绩前列并由组委会通知的队伍 |
| **截止** | **8月5日 23:59** |
| **后果** | 未按时提交或违规 → 取消资格，按榜单递补 |

### 阶段四 — 决赛路演

| | |
|---|---|
| **时间** | 2026年8月中旬（拟） |
| **形式** | 现场路演，抽签决定顺序 |
| **答辩** | 作品陈述 + 专家问答 |
| **缺席** | 未到现场 → 自动放弃决赛资格及奖金 |

大赛公示最终排名，拟于 9–11 月颁奖。

## 特别说明

1. 遵守法律法规、行业规定和道德规范，不得侵犯知识产权、隐私权
2. 建议与其他参赛者积极互动
3. 经参赛者同意，组委会可分享优秀作品至宣发平台
4. **严禁作弊** — 查实即取消资格及成绩，追回奖金
5. 组委会保留最终解释权，有权调整竞赛流程
6. 请加入官方钉钉答疑群（赛题页二维码）
