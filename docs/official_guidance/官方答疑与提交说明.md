## 一、结果通知及提交说明

> **适用范围：** 下列「18:00 → 次日 08:00」原文描述的是 **A榜** 即时反馈窗口。  
> **B榜已改用新窗口：** 交易日 T 的预测须在 **T+1 日 15:00 – T+2 日 14:59** 提交（详见 [`b-board-rules.zh.md`](./b-board-rules.zh.md) §二）。  
> `transaction_date` = 被预测交易日 的约定 **不变**。

**【结果通知及提交说明】**（A榜原文，历史保留）

由于数据 T+1 滞后的原因，我们会在每晚 18 点左右更新昨日答案，大家可以在更新答案后，将昨日预测的结果于答案更新后，第二天 8 点前上传，可以看到一个即时的分数，大家也可以通过这个验证下效果，目前分数不是最终结果。

**注：`transaction_date` 的格式需为昨日日期，不然会出错。**

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 评测节奏 | 数据滞后：当日无法拿到当日真值；提交的是样本对应交易日的答案 |
| A榜即时反馈窗口（历史） | 答案约 **18:00** 更新 → 次日 **08:00** 前上传 |
| **B榜提交窗口（现行）** | **T+1 15:00 – T+2 14:59**；样本 T 日 10:00–12:00；答案 T 日 16:00–18:00 |
| 即时分性质 | 仅用于验证效果，**不是最终成绩**（最终为 9 日 WMA） |
| `transaction_date` | 必须填**被预测交易日**的日期，用 `dt` 字符串（如 `20260713`），不要用快照时间戳 `date` |

## 二、pattern_type 答疑

**Q3：** `pattern_type` 除了提交样例给的 10 种外，是否可以根据实际情况补充？提交样例只是例子吗？

**A3：** 选手可以自由打标签，不限个数，我们最终是通过各位标签的合理性和可解释性进行打分。

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 标签集合 | **开放词汇表**，不限于样例 10 种或 Baseline 8 种 |
| 评分侧重 | `pattern_type` 与 `pattern_explanation` 的**合理性、可解释性** |
| 与 Baseline 差异 | Baseline 固定 8 类 + 硬编码阈值仅为起点，非赛题硬性约束 |
| 建议策略 | 聚类在 bounded K（如 6–12）上由数据定个数，再映射为金融语义标签并写好解释 |

## 三、常见问题（FAQ）

| 常见问题 | 解答 |
|----------|------|
| 训练数据里只有一个股票，不应该是 100 个吗？ | 样例集确实只有一个。详细可以再阅读一下赛题文档：https://tianchi.aliyun.com/competition/entrance/532489 |
| 股票样本是官方只给股票名称，明细数据由选手自行获取吗？ | 是的，选手可以通过公开渠道获取明细数据，股票样本文件可以在赛题页面左侧【赛题与数据】栏顶端下载 https://tianchi.aliyun.com/competition/entrance/532489/information |
| 使用 API 获取的数据对不上比赛的字段，必须和比赛要求的字段完全对应上吗？还是只要是 L2 数据就行？ | 赛题是没有参考字段的，只有特征集参考，不需要和比赛要求的字段完全对应上 |
| 官方的提交样例中的数据是来源于真实市场的吗？ | 样例为随机标签，仅供选手上传参考 |

> FAQ 原文为「L2 数据」；若截图显示为「LR」，竞赛语境下应理解为 Level-2 行情数据。  
> 上表前四条与 B榜新 Q&A **重复**，下文 §六不再重述，仅交叉引用。

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 样例训练集 | `AFAC2026-training-data.xlsx` 仅 **1 只股票 × 1 天**，属正常 |
| 全量股票 | 从 Tianchi【赛题与数据】下载股票列表，**自行获取** L2 明细 |
| 输入 schema | **不必**与样例 Excel 65 列一一对应；对齐官方 **7 大类特征集**即可 |
| 提交样例 CSV | `pattern_reco` / `predict_result` 中标签为**随机占位**，不可用于训练或调参 |

## 六、B榜补充 Q&A（官方梳理 · 去重后）

> 来源：AFAC2026 赛题一 B榜官方 Q&A。已与 §二、§三重复的条目只保留指针。

### 6.1 提交与字段（已有 → 见 §三）

| 问 | 处理 |
|----|------|
| API 字段是否必须与赛题完全对应？ | **已有** — §三「不必一一对应，对齐特征集即可」 |
| 提交样例是否真实市场？ | **已有** — §三「随机标签，仅格式参考」 |
| `pattern_explanation` 必须填吗？可留空吗？ | **B榜新增：** 官方鼓励可解释性；A榜不计该字段；**B榜纳入可解释性综合评分** → 实务上**每只股票都应填写**有依据的解释 |

### 6.2 标签规则

#### 资金属性（capital）

| 问 | 答 |
|----|-----|
| `capital_type` 是游资/量化两类，还是含散户三类？ | **共三类：游资 / 量化 / 散户**（提交须用裸 `量化`，与本仓库 `config.CAPITAL_TYPES` 一致） |
| 任务一标签必须在样例范围内吗？ | `capital_type` 必须为「游资/量化/散户」，否则提交报错；**聚类标签不做限制**，鼓励可解释聚类名 |
| `capital_intention` 合法取值是买入/卖出/中性，还是含样例中的 T0？ | **不限制标签内容**；评分以 `capital_type` 做 **F1 加权**；`capital_intention` **仅作可解释性维度** |

#### 交易模式（pattern）

| 问 | 答 |
|----|-----|
| `pattern_type` 只能用样例 10 种吗？ | **已有** — §二：可自由打标签、不限个数 |
| 聚类评分用官方标准答案标签还是选手自己的？ | **基于选手自己的聚类标签**评估可解释性；不对标签内容做限制 |

### 6.3 数据与模型使用

| 问 | 答 |
|----|-----|
| 推理只能用当日 Level-2 吗？ | **不限制** |
| 可以用非 Level-2 其他数据吗？ | **可以**，仅要求预测过程**不使用未来数据** |
| 如何理解「严禁未来函数」？ | 预测所用数据不得含未来时段信息；全局归一化等特征，训练可用历史交易日 |
| 训练可用多日历史吗？ | **训练阶段数据使用不做限制**（训练+推理并非只能单日） |
| 日内不同时段风格不同，如何定主导行为？ | 基于盘中高频给出最终预测；存在主导方，判定由选手自行斟酌 |
| 当日提交是用当日数据预测次日吗？ | 基于当日 L2 预测样本对应标签；因滞后与窗口，实际提交的是**上一交易日**答案（例：窗口内提交 T 日答案，而非「预测明日」） |

### 6.4 评分逻辑

| 问 | 答 |
|----|-----|
| 行情阶段识别分、Task1 区分度/聚合度基于什么？ | 基于提交的**聚类标签**：同标签算聚合度，不同标签算区分度 |
| Task1 是否只评 `pattern_type`？`pattern_explanation` 计分吗？ | A榜不涉及 `pattern_explanation`；**B榜将该字段纳入可解释性综合评分** |

### 对本项目的含义（§六）

| 要点 | 说明 |
|------|------|
| Task2 F1 | 主抓 `capital_type` 三分类；intention 仍输出，但官方 F1 不以其为主 |
| Task1 | 自定义 `pattern_type` + **写好** `pattern_explanation`（B榜计分） |
| 数据 | 多日训练、非 L2 辅助均可；推理禁未来信息 |
| 运营日历 / WMA | 见 [`b-board-rules.zh.md`](./b-board-rules.zh.md)，勿再用 A榜 08:00 窗口 |
