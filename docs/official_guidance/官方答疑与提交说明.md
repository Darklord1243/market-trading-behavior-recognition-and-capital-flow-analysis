## 一、结果通知及提交说明

**【结果通知及提交说明】**

由于数据 T+1 滞后的原因，我们会在每晚 18 点左右更新昨日答案，大家可以在更新答案后，将昨日预测的结果于答案更新后，第二天 8 点前上传，可以看到一个即时的分数，大家也可以通过这个验证下效果，目前分数不是最终结果。

**注：`transaction_date` 的格式需为昨日日期，不然会出错。**

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 评测节奏 | T+1：当日无法拿到当日真值 |
| 即时反馈窗口 | 答案约 **18:00** 更新 → 次日 **08:00** 前上传昨日预测 |
| 即时分性质 | 仅用于验证效果，**不是最终成绩** |
| `transaction_date` | 必须填**被预测交易日（昨日）**的日期，用 `dt` 字符串（如 `20260507`），不要用快照时间戳 `date` |

## 二、pattern_type 答疑

**Q3：** `pattern_type` 除了提交样例给的 10 种外，是否可以根据实际情况补充？提交样例只是例子吗？

**A3：** 选手可以自由打标签，不限个数，我们最终是通过各位标签的合理性和可解释性进行打分。

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 标签集合 | **开放词汇表**，不限于样例 10 种或 Baseline 8 种 |
| 评分侧重 | `pattern_type` 与 `pattern_explanation` 的**合理性、可解释性** |
| 与 Baseline 差异 | Baseline 固定 8 类 + 硬编码阈值仅为起点，非赛题硬性约束 |
| 建议策略 | 聚类在 bounded K（如 6–12）上由数据定个数，再映射为金融语义标签并写好解释 |

## 三、常见问题（FAQ）

| 常见问题 | 解答 |
|----------|------|
| 训练数据里只有一个股票，不应该是 100 个吗？ | 样例集确实只有一个。详细可以再阅读一下赛题文档：https://tianchi.aliyun.com/competition/entrance/532489 |
| 股票样本是官方只给股票名称，明细数据由选手自行获取吗？ | 是的，选手可以通过公开渠道获取明细数据，股票样本文件可以在赛题页面左侧【赛题与数据】栏顶端下载 https://tianchi.aliyun.com/competition/entrance/532489/information |
| 使用 API 获取的数据对不上比赛的字段，必须和比赛要求的字段完全对应上吗？还是只要是 L2 数据就行？ | 赛题是没有参考字段的，只有特征集参考，不需要和比赛要求的字段完全对应上 |
| 官方的提交样例中的数据是来源于真实市场的吗？ | 样例为随机标签，仅供选手上传参考 |

> FAQ 原文为「L2 数据」；若截图显示为「LR」，竞赛语境下应理解为 Level-2 行情数据。

### 对本项目的含义

| 要点 | 说明 |
|------|------|
| 样例训练集 | `AFAC2026-training-data.xlsx` 仅 **1 只股票 × 1 天**，属正常 |
| 全量股票 | 从 Tianchi【赛题与数据】下载股票列表，**自行获取** L2 明细 |
| 输入 schema | **不必**与样例 Excel 65 列一一对应；对齐官方 **7 大类特征集**即可 |
| 提交样例 CSV | `pattern_reco` / `predict_result` 中标签为**随机占位**，不可用于训练或调参 |
